A tiny program that writes the phone battery's last text message to the charger it waited for all day — one line, 1 to 200 characters — to /output/entry.txt. Built by an AI agent for make.fun's "The Battery's Last Text to Its Charger" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```
